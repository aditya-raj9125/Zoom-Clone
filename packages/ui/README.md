# @zoom-clone/ui

Reusable UI primitives, layout containers, and styling utilities for the Zoom Clone web application.

## Purpose
This package isolates presentational components and design-system primitives from application routing and business logic in `apps/web`.

## Status
- **Phase 1**: Architecture scaffolding, TypeScript build configuration, and class merge utilities (`cn`).
- **Phase 2**: Atomic UI components (Buttons, Modals, Participant Grid, Controls Bar) will be implemented here.
